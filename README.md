[ Matrizes em Linguagem C , Sistema De Controle De Pneus]

> Status do Projeto: 🏁 Concluído 

Um projeto eficiente para simular um sistema de controle de pneus de caminhões permitindo escolher o tipo de eixo, atribuir numeros aos pneus, mostrar pneus, realizar o rodízio de pneus e steps, mostrar o desenho das posições dos pneus e uma tela de explicação sobre os tipos de eixos disponíveis.

---

## Funcionalidades

- [x] Tipo de eixo e preencher pneus
- [x] Mostrar pneus/steps
- [x] Realizar rodízio de pneus
- [x] Mostrar desenho do layout dos pneus
- [x] Tela de legenda dos eixos

---

## 🛠️ Tecnologias Utilizadas

- Linguagem: C
- Paradigma do Projeto: Imperativo e Procedural: O desenvolvimento foi focado em sequências de instruções organizadas em funções e rotinas reutilizáveis para manipular os dados do programa.
- IDE / Editor: Code Blocks
- Controle de Versão: GitHub
